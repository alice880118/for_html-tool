操作說明

0. 元件庫與拖曳新增

  • 上方切換「頁面編輯 / 元件庫」。元件庫列出 demo 中實際存在的所有元件（依類型分類），每張卡片有即時外觀、尺寸、顏色、字體、圓角、內距、狀態切換，以及在 demo 中的使用位置與數量。
  • 點選卡片即可在右側修改名稱與樣式；修改會同步到頁面上所有使用該元件 / 變體的實例。每個元件的標題列可以「＋ 變體」「⧉ 複製元件」「✎ 重新命名」「刪除」；左側「＋ 新增元件」會先讓你選擇基礎類型，再命名與設定起始樣式。刪除前會列出受影響的頁面實例。
  • 頁面編輯左側的「元件面板」可以把元件拖到頁面上：綠色線條代表插入到某個元素的前方 / 後方，綠色框代表放入容器內部。放置後可以修改文字、icon、內容與變體，用 ↑ ↓ / 移出容器或直接拖曳來移動，按 Delete 刪除。
  • 「儲存」（Ctrl+S）存到這個瀏覽器；「重設」還原全部。匯出的 HTML 內含放置的元件與元件庫樣式，可獨立開啟。

1. 選取元件

  • 「⌖ 選取模式」開啟時（快捷鍵 V），在預覽中點到元件（按鈕、標籤、卡片…）只會選取、不會觸發它原本的互動；點到非元件區域（彈窗遮罩、關閉鈕、導覽連結）則照常運作。
  • 關閉選取模式即可正常操作 demo（切頁、開啟 Agent 視窗、下拉選單…）；此時按住 Alt 點擊仍可選取。
  • 左側清單列出每個元件的變體與「本頁可見 / 全部」數量，點變體可直接選取，按 ≡ 展開所有實例（會自動切換到該實例所在頁面）。
  • 「↖ 外層」可從按鈕跳到外層的卡片等元件。

2. 修改整個變體 vs 只改這個實例

  • 修改整個變體：改的是 token（寫入 design-system.css），所有同變體元件同步更新，預覽中以藍框標示受影響的實例。設定分三層：變體樣式（例如 Primary）、尺寸（md / sm，不分變體）、元件共用。
  • 只改這個實例：只影響選取的那一個（橘色標示已覆寫欄位，↺ 還原單一欄位）。即使 demo 重新渲染該區塊也會自動套回。
  • 顏色類設定依主題分開：在 Dark 時修改只影響 Dark，切到 Light 再調整 Light 的值。實例覆寫不分主題。

3. Icon

  • Button 可設定左 / 右 icon：選擇圖示新增或替換、✕ 移除、⇄ 左右互換。
  • 變體模式下「保持原樣」代表沿用每顆按鈕原本的 icon。

4. 設計設定

  • 左側「設計設定」可修改全站顏色、字體、圓角、間距、陰影，所有引用的元件即時更新。

5. 儲存與匯出

  • 編輯內容會自動存在這個瀏覽器；Ctrl+Z / Ctrl+Shift+Z 復原與重做。
  • 「匯出」可下載 dexless.html + design-system.css、單一 HTML 檔、tokens.json，或儲存編輯設定檔以便之後匯入。
