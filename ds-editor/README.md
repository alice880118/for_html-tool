# DEXLESS Design System Editor

以 `dexless-prototype-v1.html` 為基礎建立的可操作 Design System 編輯工具。

## 檔案

| 檔案 | 說明 |
|---|---|
| **editor.html** | 編輯工具。直接雙擊，用 Chrome / Edge 開啟即可，不需要伺服器。 |
| **dexless.html** + **design-system.css** | 整理後的原型，HTML 與 CSS 分開，兩個檔案放在同一個資料夾即可開啟。 |
| **dexless.standalone.html** | 同上，但 CSS 內嵌成單一檔案。 |
| **DESIGN-SYSTEM.md** | 元件與設計設定清單，包含每個變體的 token 與數值。 |
| `src/` | 原始碼：`ds-core.js`（token 與元件規格、CSS 產生器）、`ds-runtime.js`（實例覆寫）、`editor.js`、`editor.template.html`、`dexless.html`（整理後的原型）。 |
| `tools/` | `migrate.mjs`（從原檔抽出樣式的遷移腳本，每條替換都有檢查）、`build.mjs`（產生上面四個檔案）、`docs.mjs`（產生清單）。 |

修改 `src/` 後，執行 `node tools/build.mjs && node tools/docs.mjs` 重新產生輸出檔。

## 操作說明

### 介面
- **左側**：元件清單（數字為「本頁可見 / 全部」實例數）、設計設定、實例覆寫紀錄。
- **中間**：demo 即時預覽。工具列可以切換頁面、Dark / Light、Stable / Unstable、預覽寬度 1440 / 1024 / 390，以及縮放。
- **右側**：屬性面板。

### 選取元件
1. **選取模式**（工具列 ⌖，或按 `V`）開啟時，在預覽中點到元件只會選取它，不會觸發原本的互動。點到其他區域（例如開場彈窗的遮罩或關閉鈕、導覽連結）則照常運作。
2. 關閉選取模式後可以正常操作 demo，例如開啟 Agent 視窗、下拉選單。此時按住 `Alt` 點擊仍然可以選取。
3. 也可以從左側清單點選變體；按 `≡` 會列出所有實例，點選後會自動切換到該實例所在的頁面。
4. 「↖ 外層」可以從按鈕往外選到它所在的卡片。按 `Esc` 取消選取。

### 修改整個變體 vs 只改這個實例
- **修改整個變體**：修改 token，所有同變體的元件都會同步更新，預覽中會用藍框標出受影響的實例。面板分成三層：
  - **變體樣式**：例如只影響 Primary。
  - **尺寸**：md / sm，會影響所有同尺寸的按鈕，不分變體。
  - **元件共用**。
- **只改這個實例**：只影響選取的那一個元件。已覆寫的欄位以橘色標示，按 ↺ 可以還原單一欄位，「重設此實例」可以全部還原。即使 demo 用 JS 重新渲染了那個區塊，修改也會自動套回。
- 顏色類設定依主題分開儲存：在 Dark 主題下修改只影響 Dark。實例覆寫則不分主題。
- 顏色欄位接受任何 CSS 值：色票、`#hex`、`rgba()`、`var(--token)`，也可以從「Token…」選單直接套用設計設定。

### Icon（Button、Icon Button）
- 左 / 右 icon：點選欄位後從 sprite 圖示中挑選，可以新增或替換；按 ✕ 移除；按 ⇄ 左右互換。
- 變體模式下的「保持原樣」代表沿用每顆按鈕原本的 icon。

### 設計設定
左側「設計設定」可以調整全站的顏色、字體、圓角、間距、陰影，所有引用到的元件會即時更新。

### 元件庫
上方切換「頁面編輯 / 元件庫」。
- 依類型列出 demo 裡實際存在的元件，只列出頁面上找得到實例的元件。
  - **Token 化元件**：Button、Icon Button、Pill、Chip、Tabs、Card、Input、Toggle。
  - **尚未 token 化的元件**：Option Tabs、Segmented、底線分頁、Table、Progress bar、Pagination、Dropdown、Popup、Toast、Search、Checkbox、Badge、Severity tag、Grade chip、Avatar、Coin、Key-value、Tip、Chart。
- 每張卡片顯示即時外觀、實際尺寸、背景、文字色、字體、圓角、內距、邊框、陰影，以及在 demo 中的使用頁面與數量。卡片下方可以切換狀態（Hover、Disabled、On / Off），按鈕類會同時顯示 md / sm。
- 點選卡片後，右側可以改名稱與樣式，包括寬高、內距、字體、字級、顏色、邊框、圓角、陰影和 icon。修改會同步到頁面上所有同元件、同變體的實例。
- **新增元件**：左側「＋ 新增元件」，先選基礎類型，再命名、選擇起始樣式。
- **新增變體**：元件標題列的「＋ 變體」，例如為 Button 加 Outline。
- **複製、重新命名、刪除**：「⧉ 複製元件」「✎ 重新命名」「刪除」在元件標題列；右側面板也有「⧉ 複製變體」「刪除變體」。
- 自訂元件與自訂變體有自己的 token（`--btn-{id}-*`）和 class（`ds-v-{id}`、`ds-c-{id}`），修改時不會影響原有變體。
- **刪除**：確認視窗會列出受影響的頁面與實例數。刪除原有變體時，頁面上的實例會被隱藏（`display:none`），可以從左側「已刪除」還原。刪除自訂元件時，拖入頁面的實例會一併刪除。
- **尚未 token 化的元件**：修改會寫成 `design-system.css` 第 5 節的規則。顏色依 Dark / Light 分開儲存。
- 「盤點報告」列出辨識到的元件、重複但樣式不一致的項目，以及適合拖放的區塊。

### 拖曳新增元件（頁面編輯）
- 左側「元件面板」按住任一元件，拖到頁面上。綠色線條表示插入到元素的前方或後方，綠色框表示放入容器內部。
- **可放置的容器**：`.page`、`.gwrap`、`.card`、`.sub-card`、`.acts`、`.row`、`.g2`、`.g3`、`.g4`、`.flt` 等。
- **不可放置**：頂部導覽、側欄、Demo 控制列、浮動 Dock、表格內部。
- 開場彈窗打開時會擋住頁面，要先把它關閉。
- 放置後會自動選取該元件，右側「放置的元件」可以修改：
  - 文字、選項、標題與內文。
  - 變體與尺寸。
  - icon：切到「只改這個實例」後設定。
- **移動**：用 ↑、↓、「移出容器」，或在選取模式下直接拖曳該元件。
- **複製與刪除**：「⧉ 複製」，或按 `Delete` 刪除。
- 樣式一樣可以選「修改整個變體」（影響所有同變體實例）或「只改這個實例」。

### 儲存與匯出
- 編輯內容會自動儲存在這個瀏覽器中，也可以按「儲存」（`Ctrl+S`）立即儲存。`Ctrl+Z` 復原，`Ctrl+Shift+Z` 重做；「重設」會把所有內容還原成原始狀態，包括元件庫與拖入的元件，重設後也可以 `Ctrl+Z` 復原。
- 「匯出」選單：
  - **HTML + CSS**：下載 `dexless.html` 與 `design-system.css`。
  - **單一 HTML 檔**。
  - **tokens.json**。
  - **編輯設定 .json**：可以之後再匯入，繼續編輯。
- 匯出的 HTML 內含 `ds-runtime.js`、實例覆寫資料和拖入元件的規格，所以獨立開啟時，實例修改、icon 變更和拖入的元件都會保留。原本的頁面互動與響應式版面不受影響。

## 整理了哪些東西、如何確認沒有改到版面

- 原檔的 CSS 由 30 多個補丁區塊層層覆寫。例如 primary 按鈕背景被改寫了 4 次，5 個不同名稱的品牌色變數互相覆蓋。這次把 8 個元件（Button、Icon Button、Pill、Chip、Tabs、Card、Input、Toggle）的樣式，以及全站的色彩、字體、圓角、陰影、間距，整理成 `design-system.css` 裡的 token，並從原檔移除被取代的舊宣告，共 51 處精確替換，見 `tools/migrate.mjs`。
- 驗證方式：用 headless Chrome 逐一開啟 16 個頁面 × Dark/Light × Stable/Unstable，並在 1440 / 1024 / 390 三種寬度下，比對原檔與整理後每個元素的 30 項計算樣式，結果**差異為 0**。另外也比對了 38 個 hover 狀態，**差異同樣為 0**。
- 原檔既有的問題維持原樣、沒有修正：
  - 分頁器選中頁 `.pg span.on` 是白底白字，因為 `--violet` 已被改成白色。
  - `.sev.high` 的註解寫的是橘色，實際顯示萊姆色。

## 已知限制
- 實例是用「元件、變體、尺寸、所在頁面、文字、同名序號」來辨識。如果 demo 的資料讓按鈕文字改變了，該實例的覆寫就不會再套用（變體層級的修改不受影響）。
- 版面專屬規則會蓋過變體 token，所以修改變體時這些按鈕不會跟著變。這是為了保留原版面，這些規則列在 `DESIGN-SYSTEM.md` 的「情境調整」中：
  - `.behavior-actions .btn` 與訊號卡 `.sgc2 .btn` 的字級與內距。
  - 行動版部分 `.agb` 的尺寸。
  - Unstable 狀態下的 `.chip2.down-chip`。

  用「只改這個實例」修改時不受這些規則限制。
- 標記為 Chip、Tabs、Input、Toggle 的元件，大多出現在 Trade、Settings、Performance 等頁面，Overview 頁上看不到。請先用工具列切換頁面再選取。
- 拖入的元件用「最近的 id、頁面或全域頁 ＋ 子元素索引」記錄位置。
  - demo 用 JS 重新渲染某個區塊時，只要結構相同，元件就會自動補回。
  - 結構改變時（例如 Unstable 狀態的項目數不同），元件會暫時不顯示，右側會提示「找不到插入位置」。
- demo 有一段腳本會把按鈕列中的主要按鈕固定排在最右邊，所以拖進按鈕列的 Primary 按鈕可能會被排到最後，匯出後也一樣。
- 「尚未 token 化」元件的規則以 `.frame 選擇器` 的形式輸出。更具體的版面專屬規則仍會優先，跟變體 token 的限制相同。
- 拖曳新增、移動與選取，都需要在預覽中開啟選取模式或按住 Alt。
